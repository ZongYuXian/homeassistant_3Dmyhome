Fully offline, fully client-side 3D house plan visual effect diagram, we need to improve it together! There are many bugs that need to be fixed, and many features can be added. 1: It can run on the Android app client, or be embedded into a webpage for use in Hass; 2: Weather and time functions need to be added, and the rendering of 3D scene effects should be enhanced based on weather and time; 3: Let's improve it together, my friends! 4: Simply open index.html to run and use it. If you want to add a local glb model, please modify the img/models.json file, add textures.json for textures, sky.json for HDR textures, and finally place all files in GLB, HDR, JPG formats under the img directory; refresh the webpage to reload all files. 5: Just add the ha address and token.
